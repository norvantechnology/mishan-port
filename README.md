# Mishan Savaliya — Portfolio

Modern developer portfolio built with Next.js 14, TypeScript, Tailwind CSS, and Framer Motion.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Customize

- Resume content: `lib/data.ts`
- Update social links, email, and `siteConfig.url` after deploying to Vercel
- Update `metadataBase` / Open Graph URL in `lib/data.ts` (`siteConfig.url`)

## Deploy on Vercel

1. Push this repo to GitHub
2. Import the project at [vercel.com](https://vercel.com)
3. Deploy with default Next.js settings
4. Update `siteConfig.url` in `lib/data.ts` to your live URL
